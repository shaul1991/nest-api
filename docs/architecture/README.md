## 기술 스택

| 영역 | 기술 |
|------|------|
| Framework | NestJS 11.x |
| Language | TypeScript 5.7 |
| Database | PostgreSQL 18 |
| Cache | Redis 8 |
| ORM | TypeORM 0.3 |
| Container | Docker |
| Reverse Proxy | Caddy |
| CI/CD | GitHub Actions + Jenkins |
