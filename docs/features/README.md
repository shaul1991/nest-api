## 새 기능 문서 작성 가이드

### 디렉토리 구조

```
features/
└── <기능명>/
    ├── README.md           # 기능 개요 및 사용법 (필수)
    ├── api-reference.md    # API 엔드포인트 (선택)
    └── implementation.md   # 구현 상세 (선택)
```

